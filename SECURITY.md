# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Report it privately through GitHub's security advisory process or contact the repository owner through GitHub.

Include the affected component, reproduction steps, impact, and any suggested mitigation. Please avoid including secrets or personal data in the report.

## Local secrets

Copy the appropriate `.env.example` files for local development. Never commit `.env` files, database files, private keys, or production credentials.
